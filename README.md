# SlideTranslate AI 🌐📊

PowerPoint (.pptx) taqdimotlarini **100% asl dizayni, ranglari, shakllari, jadvallari va shriftlarini saqlagan holda** O'zbek tiliga (Lotin va Kirill alifbosida) professional tarjima qiluvchi veb-ilova.

## 🚀 Ishga tushirish (1 ta buyruq)

1. Ushbu papkada terminal oching va quyidagilarni bajaring:
`ash
python start_app.py
`
yoki Windows da shunchaki **start.bat** faylini sichqoncha bilan 2 marta bosing!

2. Veb-ilova avtomatik tarzda brauzerda ochiladi:
- **Veb-ilova:** http://localhost:5173
- **Backend API:** http://localhost:8000/docs

## 🌟 Imkoniyatlar:
- 💎 **100% Format Saqlanishi**: Barcha shakllar, ranglar, qalin/qiya shriftlar buzilmaydi.
- ⚡ **Auto-Fit Shrift Moslash**: Matn toshib ketishini oldini oluvchi avtomatik shrift o'lchamini moslash.
- 🔤 **Lotin & Кирилл**: Bitta tugma orqali alifbolarni almashtirish va transliteratsiya.
- 🧠 **Gemini 3.6 / 3.7 Flash**: Sohaviy adabiy o'zbek tilida aniq tarjima.
- 📖 **Maxsus Lug'at (Glossary)**: Maxsus korporativ va IT terminlarini qulflash.
- 🎨 **Split-Screen Studio**: Slaydma-slayd jonli ko'rish va yuklab olishdan oldin tahrirlash (Inline Edit).
